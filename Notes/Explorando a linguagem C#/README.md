# 🎯 Exploração Avançada C# (.NET)

O objetivo principal deste módulo é expandir os horizontes sobre a linguagem C#, saindo do básico e explorando recursos avançados que conferem **robustez**, **performance** e **escalabilidade** às aplicações.

## 📝 Pré-requisitos

Antes de iniciar esta jornada, é fundamental que você tenha domínio sobre:

* **Módulo Fundamentos:** Sintaxe básica, tipos de dados e operadores. 🧩
* **Algoritmos e Lógica de Programação:** Estruturas de decisão e repetição. 🧠

---

## 🗺️ Percurso de Aprendizado:

A trilha está dividida em 7 etapas estratégicas para consolidar seu conhecimento como desenvolvedor .NET:

### 1. Propriedades, Métodos e Construtores 🏗️

Aprofundamento na Programação Orientada a Objetos (POO). Como encapsular dados corretamente e garantir que um objeto seja criado de forma válida desde o primeiro segundo.

### 2. Manipulando Valores ⚙️

Trabalho com strings, tipos numéricos e, principalmente, a formatação de moedas e datas seguindo padrões internacionais (Globalization).

### 3. Exceções e Coleções 🛡️

Como tornar seu código "à prova de falhas" com blocos [`try-catch`](https://github.com/CarvalhoNathan/tivit-net-github-copilot/tree/main/Exce%C3%A7%C3%B5es%20e%20Cole%C3%A7%C3%B5es) e o uso de coleções avançadas como [`Queue`, `Stack` e `Dictionary`](https://github.com/CarvalhoNathan/tivit-net-github-copilot/tree/main/Filas%20e%20Pilhas).

### 4. Tuplas, Operador Ternário e Desconstrução ⚡

Recursos modernos do C# para escrever códigos mais limpos, concisos e performáticos ao retornar múltiplos valores ou tomar decisões rápidas.

### 5. NuGet, Serialização e Atributos 📦

O ecossistema .NET: Como consumir pacotes externos, transformar objetos em arquivos JSON (Serialização) e usar metadados (Atributos) para decorar seu código.

### 6. Tipos Especiais no C# ✨

Exploração de tipos como `Anonymous Types`, `Dynamic`, `Nullables` e extensões de métodos que dão superpoderes às classes existentes.

### 7. Gestão de Memória: Stack, Heap e Garbage Collector 🧬

O "sob o capô" do .NET. Entenda como a memória é alocada e como o sistema limpa os recursos automaticamente para manter a aplicação rápida.

---

## 🚀 O que você será capaz de fazer?

Ao final deste percurso, você deixará de apenas "escrever código" para começar a **projetar soluções** eficientes, entendendo não só *como* fazer, mas o *porquê* de cada escolha técnica dentro do ecossistema Microsoft.
